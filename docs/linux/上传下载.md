## rz/sz

sz 和 rz 是 Linux 服务器与本地电脑之间传输文件的命令行工具，核心区别在于方向：sz 用于‌下载‌（服务器 → 本地），rz 用于‌上传‌（本地 → 服务器），都基于 ZMODEM 协议。‌‌

## 安装方法

服务器端需要安装 `lrzsz` 软件包，根据不同系统选择命令：

```bash
# CentOS/RHEL
yum install -y lrzsz（新版用 `dnf`）

# Ubuntu/Debian
sudo apt-get install -y lrzsz

# openSUSE
sudo zypper install lrzsz
```

## 上传

‌上传文件（本地 → 服务器）

```bash
rz
```

执行后会自动弹出文件选择窗口，选好文件即可上传到当前目录。建议用 `rz -be`，其中 `-b` 以二进制传输、`-e` 转义控制字符，能保证文件内容一致。‌‌

## 下载

‌下载文件（服务器 → 本地）

```bash
sz filename          # 下载单个文件
sz file1 file2       # 下载多个文件
sz *.log             # 用通配符批量下载
```
